# eitechlegal.com

Source for the [EiTech Legal](https://eitechlegal.com) website, operated by EiTech Advisory Group (Singapore). The site describes our DPDP and PDPA compliance, cybersecurity and data security consulting services.

EiTech Advisory Group provides compliance and technical consulting only. It is not a law firm and does not provide legal advice.

## Structure

| File | Purpose |
|---|---|
| `index.html` | Homepage: services, about, contact form |
| `dpdp.html` | India DPDP Act compliance services |
| `india.html` | India services and resources |
| `resources.html` | Singapore compliance and cybersecurity resources |
| `privacy.html`, `terms.html` | Privacy policy and terms of use |
| `thanks.html` | Contact form confirmation page |
| `assets/` | Shared mobile-menu CSS/JS, favicons, social share image |
| `sitemap.xml`, `robots.txt` | Search engine files |

## Hosting

Static HTML on GitHub Pages with the custom domain in `CNAME`. Pushing to `main` publishes the site within a few minutes. The contact form is delivered by [FormSubmit](https://formsubmit.co) to contact@eitechlegal.com.
